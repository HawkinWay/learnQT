# Object Introspection

In this section, we explore how to inspect QObject at runtime using the meta object system. Now that we understand how to create signals, slots, and properties, we can examine how Qt keeps track of all these features behind the scenes. This ability to query an object about its own structure is called introspection, and it is one of the powerful capabilities that the meta object system provides.

By the end of this section, you will be able to use the QMetaObject to retrieve information about a QObject's class name, superclass, properties, methods, and enumerators at runtime.

## Inspecting the Meta Object

Now that we understand how to create signals, slots, and properties, we will now investigate how to inspect the meta object at run time. The meta object refers to the aspects of a class which are generated by the Meta Object Compiler. These aspects generally refer to QProperties, signals, slots, and QEnums, all of which have additional code associated with them which is generated as part of the meta object system. Since this code is not written by the developer, it can be useful to introspect this code at runtime. Information on these features can be accessed through the QMetaObject(opens in a new tab) returned by the metaObject()(opens in a new tab) function of any QObject. The metaObject is a struct which holds useful information about the QObject class such as the class name, superclass name, property count, among other useful bits of information.

```cpp
#include <QDebug>
#include <QMetaObject>
#include <QMetaProperty>
#include "myqobject.h"

int main(int argc, char *argv[])
{
    QCoreApplication a(argc, argv);

    MyQObject *object = new MyQObject(&a);

    // Print class information
    qInfo() << "Class name:" << metaObject->className();
    qInfo() << "Superclass name:" << metaObject->superClass()->className();
    qInfo() << "Property count:" << metaObject->propertyCount();
    qInfo() << "Method count:" << metaObject->methodCount();
    qInfo() << "Enumerator count:" << metaObject->enumeratorCount();

    return a.exec();
}
```

The above example demonstrates the use of QMetaObject to print information about a custom QObject.
